# Test System (Tkinter) — Version 2.0

Простой интерактивный тест на Python с графическим интерфейсом на Tkinter. Вопросы хранятся в JSON, порядок вопросов перемешивается, результат подсчитывается автоматически. Проект был написан от руки и самостоятельно до версии 1.0

## 🚀 Что нового в версии 2.0 (Stabilized Release)

В этой версии я сфокусировался на стабильности и гибкости интерфейса, решив ключевые проблемы первой версии:

*   **Динамические кнопки:** Реализована логика, при которой количество кнопок (`Radiobutton`) подстраивается под число вариантов ответа в JSON. Старые кнопки корректно удаляются перед отрисовкой новых, что исключает наложение элементов и ошибки интерфейса.
*   **Защита от падений:** Добавлена обработка ошибок при отсутствии файла `questions.json`. Теперь программа не выбрасывает traceback-ошибку в консоль, а показывает понятное предупреждение через `messagebox`.
*   **Стабильность навигации:** Исправлена логика переключения между вопросами, чтобы избежать ошибок индексации (`IndexError`) при достижении конца списка вопросов.

## 🛠 Функционал

*   Отображение вопросов и вариантов ответов (Radiobutton).
*   Проверка выбранного ответа и подсчёт правильных ответов.
*   Перемешивание порядка вопросов при старте (`random.shuffle`).
*   Финальный экран с результатом (количество правильных ответов и процент).
*   Обработка крайнего случая: корректная остановка теста по лимиту вопросов.

## ▶️ Как запустить

1.  Убедитесь, что установлен Python 3.x.
2.  Клонируйте репозиторий или скачайте файлы.
3.  Убедитесь, что файл `questions.json` находится в той же папке, что и `main.py`.
4.  Запустите проект:
    ```bash
    python main.py
    ```
